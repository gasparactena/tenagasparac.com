# Tena Gasparac — Portfolio Website

Responsive editorial portfolio built with HTML, CSS and vanilla JavaScript. Approved black / ivory / burgundy visual direction.

## Files
- index.html — Home, Portfolio, Recommendations, About and Contact.
- styles.css — responsive styling and imagery.
- script.js — navigation, mobile menu and email-client contact form.
- projects.js — NAS Daily video configuration.

## Before public launch
- Replace YOUR-EMAIL-HERE in index.html and script.js with the preferred contact email.
- Confirm testimonial wording and permission to publish.
- Confirm permission to feature the NAS Daily videos.
- Replace education placeholders if added later.

## Contact form
The static form opens the visitor's email application with a prefilled message. It does not send or store submissions on a server.
